# 声桥 2.1：Windows 实机回归清单

云端交叉构建和自动化设置测试不是 Windows 实机验收。基线：和声桥 2.0 用同一个无声虚拟播放来源与两台实体输出，旧版先退出。

1. 首启且不勾任一开关：重开应用不自行开始播放，不登记登录启动。
2. 只开「登录 Windows 时启动」：注销再登入，应用打开但没有播放。同一个 Windows 用户的“启动”列表中可以停用。手动提前打开时不启动第二个实例。
3. 再开自动保持，手动确认固定的一组输出并开始。关闭程序而不是按停止，登录或重新启动应用后确认为同组恢复。测试应用仍由 Windows 送到同一个虚拟设备。
4. 拔掉或关闭一台外置音响，确认不会替换成其他设备；重新启用后确认原组恢复。再测试虚拟来源退出、恢复，和登录时蓝牙晚于系统就绪。普通静音/暂停不触发重连。
5. 在等待重连时按停止，确认设备回来以后仍不自动播放；退出重开后也保持停止。手动开始后恢复正常。更换来源或目标不能沿用上一次确认。
6. 取消登录自启，确认下一次登入不启动；移动 EXE 前也先取消旧路径的自启。勿通过关闭系统安全设置绕过签名提示。
