# 声桥 SoundBridge-Win

Windows 上的本机双输出同步工具。用 Windows 音频接口读取指定的播放设备，并把音频送到两个或更多你选定的扬声器、耳机或声卡。声桥本身不提供网络流、不上传录音、不改变 Windows 默认播放设备。开发预览沿用 `AudioRelay.exe` 文件名和旧版设置路径，公开项目使用 **SoundBridge-Win** 名称，与其他同名音频产品无关。

## 两种用法

1. **不装驱动。** 沿用已有的播放设备和镜像流程。Windows 照常向原设备播放，声桥把声音送到至少两台另外选定的设备。原设备的直出声音不由声桥调度，不能保证和镜像设备同时出声。此模式不是「一台原设备加一台镜像」。
2. **可选虚拟声卡桥接。** 先安装你已信任、确有可用 WASAPI 回环的静音虚拟播放设备；在 Windows「声音」或应用音量合成器中把目标应用的输出**手动**指向它。声桥里明确选择这个播放设备作为音源，再选择两台不同的真实发声设备。虚拟设备本身不出声。若源设备失效，声桥不偷偷切到另一个播放设备；不能把源设备再选作目标，避免回送。程序启动新并行路由前检查所有选中的播放端点。

**v2.2 此次完成的是用户态选择和路由，不包含可一键安装的虚拟驱动。** 当前未接入通用麦克风或虚拟录音端点。若虚拟线缆只提供另一端的录音输入、播放端的 WASAPI 回环不是实际声音，此版本不能保证使用它。如何判断路线、安装建议和验收标准，见 [虚拟声卡计划](docs/virtual-audio.zh-CN.md)。

## 安装与构建

面向 Windows 11 x64。请安装 .NET 10 SDK（项目指定 10.0.404，允许同一 SDK 特性带的更新补丁）。在 PowerShell 中进入「源码」后运行：

```powershell
.\build.ps1 -Architecture win-x64
```

构建会从 NuGet 还原锁定的依赖。产物在 `源码/publish/win-x64/AudioRelay.exe`。预览版和原版共用设置，首测先退出原版，不直接覆盖它，不先开启开机启动。源码可审查不等于发布程序或驱动已签名。

可以在仓库根目录运行 `dotnet run --project 源码/validation/pinned-source/PinnedSource.csproj`，做音源选择逻辑的合成验证。真实音频、备用端点、音量和延迟，请按「源码/validation」指南在 Windows 双设备上逐项验收。每次自动测量都须在界面确认，才用默认麦克风采样并在内存处理。测量门槛不是实机已达到的指标。
